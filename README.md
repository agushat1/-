BAMParser - полезная программа которая показывает exe файлы
BrowserDowloadsView - программа которая показывает всё файлы которые ты качал через Браузер
Everything - программа для просмотра файлов
JournalTrace - тоже программа для просмотра файлов только там уже смотрят дату, и если удалить файл с компа то он там будет сохраняться некоторое время
LastActivityView - программа для просмотра файлов в формате exe которые запускали за всё время
prefetch-cmd.bat - показывает подозрительные exe файлы в формате .pf рядом также есть дата
proccesshacker - полезная программа для просмотра последних запусков или просмотра кпс/рича если кпс/рич коунтеры были включены
RegisteyFinder - программа для просмотра exe
Проверка.bat - открывает нужные вкладки для проверки, уменьшая траты времени для проверки проверяющим
USBdeview - прога для просмотра подключения мышок или флешек
UserAssistView - прога для просмотра всех exe за всё время
Для проверки.txt - вписанные команды которые пригодяться для проверки
